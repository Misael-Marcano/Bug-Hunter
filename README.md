# Bug Hunter

Arcade web Tokyo Night — caza bugs, aplica hotfixes y resuelve merge conflicts.

**Play:** https://misael-marcano.github.io/Bug-Hunter/

## Stack

- Vite + TypeScript
- Phaser 4
- GitHub Pages (Actions)

## Controles

| Input | Acción |
|-------|--------|
| A / D o ← → | Mover |
| Space / ↑ | Disparar |
| P / Esc | Pausar |
| M | Mute |
| Touch | Stick izq. + FIRE der. |

## Power-ups

| Orb | Efecto |
|-----|--------|
| Hotfix | Disparo rápido |
| Git stash | Escudo |
| Coffee | +1 vida |
| Twin | Doble disparo |
| Spread | Abanico 3 vías |
| Pierce | Balas perforantes |

Cada 5 olas aparece un boss **MERGE CONFLICT**.

## Dev

```bash
npm install
npm run dev
npm run build
```
